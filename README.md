# Python Basics – Roll No.

## Overview
This project contains basic Python programs created to understand fundamental programming concepts and the conversion of C programming concepts into Python.

## Programs Included

- **factorial.py** – Calculates the factorial of a number.
- **fibonacci.py** – Generates the Fibonacci sequence.
- **struct.py** – Demonstrates structured student data using Python.

## Technologies Used

- Python
- GitHub
- Google Gemini

## How to Run

Clone the repository and run any program using:

```bash
python factorial.py
python fibonacci.py
python struct.py
